# demo

Skelettfil: projektets egen efter första genereringen.

Projektet är skapat från projektbasen. Filer med prefixet `pb-` (`project base`) ägs av mallen: de ändras bara genom en mallupdate och handredigeras aldrig. Projektets egna filer har inget `pb-`-prefix. Arbetsmetoden står i `.claude/rules/pb-workflow.md`.
