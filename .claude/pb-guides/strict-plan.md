# Strict-plan: frågorna under `Security`

Svara bara på frågorna som berör ändringen. Ange sökväg eller beteende för varje svar. Rubriken får inte vara tom.

- Vem får göra detta?
- Vilken data exponeras?
- Vad händer vid manipulation?
- Hur valideras input?
- Hur hanteras secrets?
- Vad loggas?
- Kan information läcka?
- Vad händer vid fel?

Om ändringen lägger till eller ändrar en förtroendegräns eller angreppsyta: uppdatera hotmodellen i samma PR och ange det här.
